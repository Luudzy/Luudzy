## 🔨 O que estou construindo

### Zenkai

Modelo e pipeline de **upscaling voltado para anime**.

A ideia do projeto é conseguir melhorar imagens e vídeos mantendo modelos pequenos e rápidos o suficiente para rodar até em hardware mais limitado.

Tenho trabalhado com:

- PyTorch
- ONNX
- ONNX Runtime
- ROCm
- DirectML
- FP16
- treinamento de modelos
- processamento de imagens
- benchmark de qualidade e desempenho

Um dos maiores focos do projeto é experimentar otimizações para **GPUs AMD**, principalmente hardware que normalmente recebe pouco suporte para IA.

---

### FeatherBrowser

Um navegador experimental criado com uma proposta simples:

> **ser leve sem parecer um navegador de 2008.**

O projeto busca reduzir uso de memória e processos desnecessários mantendo uma interface moderna.

Algumas coisas que venho experimentando nele:

- interface minimalista
- modo escuro
- otimização de RAM
- integração com MPV
- yt-dlp
- carregamento de páginas
- arquitetura mais enxuta

---

### BSK.GG

Projeto de análise para **League of Legends**.

Nasceu da minha experiência com competitivo e da vontade de transformar dados de partidas em informações realmente úteis.

O projeto trabalha com ideias como:

- histórico de partidas
- desempenho por campeão
- comparação entre jogadores
- gráficos
- heatmaps
- scouting
- dashboards
- análise de performance

Também é ligado à **Basilisk e-Sports**, projeto de equipe que mantenho há alguns anos.
